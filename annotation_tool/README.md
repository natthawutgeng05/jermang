# Desktop Annotation Tool

เครื่องมือ annotation แมลงแบบ desktop application ที่ใช้ PySide6

## การเริ่มต้นใช้งาน

```bash
python desktop_annotation_tool.py
```

## คุณสมบัติ

### การใช้งานพื้นฐาน

1. **เพิ่มรูปภาพ**: คลิก "เพิ่มรูปภาพ" หรือ "เปิดโฟลเดอร์"
2. **เลือกรูป**: คลิกที่รูปในรายการด้านซ้าย
3. **เลือกโหมด**: เลือก "วาด Bounding Box"
4. **เลือกคลาส**: เลือกชนิดแมลงจาก dropdown
5. **วาด annotation**: ลากเมาส์เพื่อวาดกรอบ
6. **บันทึก**: คลิก "บันทึก Annotation"

### การจัดการ Annotation

- **เลือก/แก้ไข**: เปลี่ยนเป็นโหมด "เลือก/แก้ไข" แล้วคลิกที่กรอบ
- **ลบ**: เลือกกรอบแล้วกดปุ่ม Delete หรือคลิก "ลบที่เลือก"
- **ลบทั้งหมด**: คลิก "ลบทั้งหมด"

### การจัดการคลาส

- **เพิ่มคลาส**: เมนู "คลาส" > "เพิ่มคลาสใหม่"
- **จัดการคลาส**: เมนู "คลาส" > "จัดการคลาส"

### เครื่องมือช่วย

- **Zoom**: ใช้ปุ่ม 🔍+, 🔍-, Reset เพื่อขยาย/ย่อ
- **สถิติ**: ดูสถิติการ annotation ด้านล่างขวา
- **ส่งออก**: เมนู "ไฟล์" > "ส่งออกข้อมูล"

## คีย์บอร์ดลัด

- `Ctrl+O`: เปิดโฟลเดอร์รูปภาพ
- `Ctrl+A`: เพิ่มรูปภาพ
- `Ctrl+S`: บันทึก annotation
- `Delete`: ลบ annotation ที่เลือก
- `Ctrl+Q`: ออกจากโปรแกรม

## เคล็ดลับการใช้งาน

1. **การ annotate ที่ดี**: วาดกรอบให้แน่นกับแมลง ไม่ควรหลวมมาก
2. **ความละเอียด**: ใช้ zoom เมื่อ annotate แมลงขนาดเล็ก
3. **ความสม่ำเสมอ**: ตั้งมาตรฐานการวาดกรอบให้เหมือนกัน
4. **การตรวจสอบ**: ดูสถิติเป็นระยะเพื่อตรวจสอบความสมดุลของข้อมูล

## ไฟล์ที่สร้างขึ้น

- `../dataset/images/`: รูปภาพต้นฉบับ
- `../dataset/annotations/`: ไฟล์ .txt ในรูปแบบ YOLO
- `../dataset/classes.txt`: รายชื่อคลาสแมลง

## การแก้ไขปัญหา

- **โปรแกรมไม่เปิด**: ตรวจสอบการติดตั้ง PySide6
- **ไม่เห็นรูป**: ตรวจสอบ path และรูปแบบไฟล์
- **บันทึกไม่ได้**: ตรวจสอบสิทธิ์การเขียนไฟล์
