# Desktop Detection Tool

เครื่องมือตรวจจับแมลงแบบ desktop application ที่ใช้ PySide6

## การเริ่มต้นใช้งาน

```bash
python desktop_detection_tool.py
```

## คุณสมบัติ

### การตั้งค่าเบื้องต้น

1. **โหลดโมเดล**: คลิก "โหลดโมเดล" แล้วเลือกไฟล์ .pt
2. **ปรับ Confidence**: ใช้ slider เพื่อปรับระดับความแม่นยำ
3. **เลือกแหล่งข้อมูล**: เลือกระหว่างกล้อง, รูปภาพ, วิดีโอ, หรือหลายไฟล์

### แหล่งข้อมูลที่รองรับ

- **📷 กล้อง**: ตรวจจับแบบ real-time
- **🖼️ รูปภาพ**: ตรวจจับจากไฟล์รูปเดี่ยว
- **🎥 วิดีโอ**: ตรวจจับจากไฟล์วิดีโอ
- **📁 หลายไฟล์**: ประมวลผลไฟล์จำนวนมาก

### ระหว่างการตรวจจับ

- **FPS Monitor**: ดูอัตราเฟรมด้านบน
- **Detection Count**: ดูจำนวนการตรวจจับปัจจุบัน
- **Live Statistics**: ดูสถิติแบบ real-time ด้านขวา
- **Detection History**: ดูประวัติการตรวจจับ

### การบันทึกผลลัพธ์

- **📸 บันทึกเฟรม**: บันทึกเฟรมปัจจุบันพร้อม annotation
- **💾 บันทึกประวัติ**: บันทึกประวัติการตรวจจับเป็น JSON
- **📤 ส่งออกสถิติ**: ส่งออกสถิติเป็นไฟล์ text

## เมนูและฟีเจอร์

### เมนู "ไฟล์"

- `Ctrl+M`: โหลดโมเดล
- `Ctrl+S`: บันทึกผลลัพธ์
- `Ctrl+Q`: ออกจากโปรแกรม

### เมนู "ตรวจจับ"

- เริ่มตรวจจับจากกล้อง
- ตรวจจับจากรูปภาพ
- ตรวจจับจากวิดีโอ
- `Esc`: หยุดการตรวจจับ

## การใช้งานเฉพาะแต่ละประเภท

### กล้อง Real-time

1. เลือกกล้อง (Camera ID)
2. คลิก "เริ่มตรวจจับ"
3. ดูผลการตรวจจับแบบ live
4. กด Esc เพื่อหยุด

### รูปภาพเดี่ยว

1. เลือกไฟล์รูปภาพ
2. ดูผลการตรวจจับทันที
3. บันทึกผลลัพธ์ได้

### วิดีโอ

1. เลือกไฟล์วิดีโอ
2. ดูการประมวลผลแต่ละเฟรม
3. ดูสถิติรวม

### Batch Processing

1. เลือกโฟลเดอร์ที่มีรูปภาพ
2. ดูความคืบหน้าการประมวลผล
3. รับผลสรุปและสถิติ

## ไฟล์ผลลัพธ์

### รูปแบบไฟล์ที่บันทึก

- **detection_YYYYMMDD_HHMMSS.jpg**: เฟรมที่บันทึก
- **detection_history_YYYYMMDD_HHMMSS.json**: ประวัติการตรวจจับ
- **detection_statistics_YYYYMMDD_HHMMSS.txt**: สถิติการตรวจจับ
- **batch_detection_YYYYMMDD_HHMMSS.json**: ผลลัพธ์ batch processing

### โครงสร้าง JSON ประวัติ

```json
{
  "session_info": {
    "start_time": "2025-06-26 10:30:00",
    "total_detections": 150,
    "class_counts": { "butterfly": 45, "bee": 30 }
  },
  "detections": [
    {
      "timestamp": "10:30:15",
      "detection": { "class_name": "butterfly", "confidence": 0.85 }
    }
  ]
}
```

## การแก้ไขปัญหา

### ปัญหาทั่วไป

- **โมเดลโหลดไม่ได้**: ตรวจสอบไฟล์ .pt และ ultralytics
- **กล้องเปิดไม่ได้**: ตรวจสอบ Camera ID และสิทธิ์
- **ประมวลผลช้า**: ลดขนาดรูป หรือเพิ่ม confidence threshold
- **หน่วยความจำเต็ม**: ปิดโปรแกรมอื่นหรือลด batch size

### การเพิ่มประสิทธิภาพ

- ใช้ GPU หากมี (ต้องติดตั้ง CUDA)
- ปรับ confidence threshold ให้เหมาะสม
- ใช้โมเดลขนาดเล็กกว่า (yolov8n แทน yolov8l)

## เคล็ดลับการใช้งาน

1. **ทดสอบโมเดล**: เริ่มจากรูปภาพก่อนแล้วค่อยใช้กล้อง
2. **ปรับ Confidence**: เริ่มที่ 0.5 แล้วปรับตามผลลัพธ์
3. **บันทึกผลลัพธ์**: บันทึกเฟรมที่น่าสนใจเป็นระยะ
4. **ตรวจสอบสถิติ**: ดูสถิติเพื่อประเมินประสิทธิภาพโมเดล
